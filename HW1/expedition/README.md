## 1. Условие задачи
Группа роботов исследует клеточную карту с препятствиями, опасными зонами, целями, зарядными
станциями и ретрансляторами. Роботы получают задания, едут к целям, исследуют их и передают данные
на базу. У роботов ограничены энергия, приборы и память. Связь есть только в зонах базы и
ретрансляторов; сообщения задерживаются, теряются и дублируются. Диспетчер распределяет задания и
повторно назначает потерянные после тайм-аута.

## 2. Сценарий: сущности и их отображение в программу
Программа последовательная: на каждом такте участники действуют по очереди. Каждый участник — тип
данных и функции.

| Сущность | Тип / функции | Поведение |
|---|---|---|
| Территория | `World.grid`, `map.c` | клетки, стоимость шага, поля расстояний до целей, станций и зоны связи |
| Канал связи | `Msg`, `net_send`, `net_deliver` | задержка, потеря, дублирование; роботу — только в зоне связи |
| База | `base_receive` | однократный учёт пакетов по номеру, подтверждения, «задание выполнено» |
| Диспетчер | `dispatcher_init/tick` | недоступные задания, телеметрия, тайм-ауты, назначение fifo/nearest |
| Ретрансляторы | символ `^`, `World.cover` | зоны связи вокруг базы и ретрансляторов |
| Робот | `Robot`, `robot_tick` | автомат: к цели, исследование, данные, передача, зарядка, стоянка, авария |
| Станция | `chstock`, `chargers_tick` | выдаёт энергию из запаса, может исчерпаться |

Порядок такта (`world_step`): доставка сообщений → диспетчер → роботы → станции → проверка инвариантов.
Протокол: назначение (может потеряться — тайм-аут), пакет данных, подтверждение. При входе в зону
связи робот сверяется с базой: пакеты, чьи номера база уже засчитала, считаются доставленными.

Энергия: робот берёт задание, только если энергии хватит на путь, исследование и путь от цели до
станции; иначе едет на подходящую станцию. Инварианты проверяются после каждого такта; при нарушении
программа завершается с кодом 5 — за все прогоны такого не было.

## 3. Интерфейс
- Обычный режим — поток событий по строке на событие: `[такт] ВИД текст`.
- `-m` — каждый такт перерисовывается экран: карта (роботы — цифры, X — авария, выполненные
  цели — заглавные буквы), состояние роботов, сводка, последние события.
- `-v` — дополнительно каждый шаг и каждый такт зарядки и исследования.
- Журнал `expedition.log` содержит все события и итоговый отчёт.
- Параметры: встроенный сценарий, файл сценария `-c` (формат — в начале `config.c` и в
  `tests/*.cfg`), опции командной строки.

## 4. Запуск и завершение

```bash
make
```

```bash
./expedition -m
```

```bash
./expedition -c tests/t2_lossy.cfg -s 5
```

```bash
./expedition -t 0
```

`-t 0` — без ограничения тактов, выход по Ctrl+C.

| Код | Причина |
|---|---|
| 0 | выполнены все доступные задания |
| 1 | ошибка в параметрах или сценарии |
| 2 | достигнут предел тактов |
| 3 | ресурсы исчерпаны: нет исправных совместимых роботов, кончилась энергия станций или нет прогресса |
| 4 | прервано сигналом SIGINT или SIGTERM, итоги сохранены |
| 5 | нарушен инвариант |

## 5. Результаты
- Демонстрационный сценарий (seed 7): 8 из 9 заданий выполнены за 100 тактов. Задание 'k'
  недоступно — нет магнитометра. Произошло 4 потери пакетов и 1 дубликат (отброшен базой), была
  повторная передача. Одно назначение потеряно и выдано повторно по тайм-ауту. 100 проверок
  инвариантов без нарушений.
- 30 прогонов с разными seed: все завершились кодом 0.
- `make test`: 10 из 10 проверок пройдены.
- Версия с AddressSanitizer и UBSan: 8 сценариев × 50 seed — ошибок нет.

## 6. Использование ИИ и критическая оценка
Код создан с помощью ИИ по промтам из [PROMPTS.md](PROMPTS.md). Найдено и исправлено при проверке
(промт 9):
1. Ошибка сборки (не подключён `stdio.h`) и малые буферы для русского текста.
2. Неверное сообщение после выполнения собственного задания.
3. Логическая ошибка: робот с полной батареей не ехал на промежуточную станцию и вставал на
   стоянку. Найдена тестом t4.
4. Свободный робот мог ждать задание в опасной зоне.

Ограничения модели:
- Робот после аварии не загораживает клетку.
- Сведения о выполнении задания робот получает из зоны связи без потерь.
- Завершение по отсутствию прогресса (`stall_ticks`) — эвристика.
